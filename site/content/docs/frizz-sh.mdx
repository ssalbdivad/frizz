```text
  press R, choose Private name

  Serving https://mk7w2qp9x4n3f6tbz5vh.frizz.sh (frizz.sh).
```

Your board stays on loopback and **dials out** to frizz.sh. That one fact removes the inbound port, the tunnel binary and the DNS record all at once, so a laptop behind any NAT works with no configuration. The connection comes back by itself after a sleep or a network change, so a board is reachable again as soon as the machine is.

## A private name

The default. Frizz mints an unguessable name — 20 random characters, so nobody finds it by guessing — and claims it with this machine's own key. No sign-in of any kind.

The name is the address, not the lock: the first visit from every device still needs a single-use [sign-in link](/docs/remote-access#frizz-does-the-authenticating).

## A custom name

Choose **Custom name** and pick a word to claim `<name>.frizz.sh`:

```text
  Name  ada

  claiming ada.frizz.sh for GitHub user ada
```

A chosen name can be squatted, so it costs an identity: claiming needs the [GitHub CLI](https://cli.github.com) signed in. Frizz asks `gh` for a token, the registrar spends it on your account id and discards it, and the name is bound to that account.

## Keeping a name

Your machine holds an Ed25519 key, `identity.key` in Frizz's state directory (`~/.frizz/` on an install that has one), and that key alone proves ownership. Renewals need no sign-in, and a custom name keeps working whether or not GitHub does. Ownership moves between machines the way an SSH key does: copy the file.

Every launch renews the lease. A name nobody has run for **30 days** is released, and a released custom name can be claimed by someone else.

## What you are agreeing to

- **One name per machine key, and one custom name per GitHub account.** An account less than 30 days old cannot claim a custom name.
- **The name is a lease, not property.** It lapses after 30 days unused, and Frizz can reclaim any name at any time — that is the only enforcement there is, so it has to exist.
- **Your traffic passes through us.** A name on frizz.sh is served by a relay we run: every request and every keystroke goes through it. Frizz's own access gate still runs on your machine, so a visitor meets it whether or not the relay is honest — but if you would rather no third party carried the bytes, use [a domain you control](/docs/cloudflare-tunnel).
- **No warranty.** This is a free convenience on a domain someone else owns. Anything you cannot afford to lose access to belongs on a domain you control.
